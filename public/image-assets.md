# Saturn Lines image assets

All customer-facing transport and destination artwork used by the stable UI is stored locally in `public/` and served by Vite/Vercel as static assets.

- `saturn-lines-bus-hero.svg` — local hero transport artwork
- `saturn-lines-riyadh.svg` — Riyadh destination artwork
- `saturn-lines-jeddah.svg` — Jeddah destination artwork
- `saturn-lines-makkah.svg` — Makkah destination artwork
- `saturn-lines-sanaa.svg` — Sana'a destination artwork
- `saturn-lines-aden.svg` — Aden destination artwork
- `saturn-lines-hadhramaut.svg` — Hadhramaut destination artwork

No image-download script is required during the Vercel build.
